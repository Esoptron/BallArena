# Тестовый APK для Android

Описание ранее подготовленного тестового APK, а не сборки после каждого изменения проекта. Новый APK создаётся только по отдельному запросу владельца.

Сборка: Godot 4.7.2, профиль `Android Test`, пакет `com.esoptron.ballarena.test`, версия `0.1-test` (код 1). Это подписанный отладочный APK для установки напрямую на телефон. Поддерживаются ARM64 и ARMv7, Android 7.0/API 24 и новее. Интерфейс работает горизонтально.

## Установка на телефон

1. Перенесите `BallArena-test.apk` на телефон через USB, облако или мессенджер как файл.
2. Откройте APK в файловом менеджере. Если Android попросит, разрешите этому приложению установку из этого источника.
3. Нажмите «Установить» и откройте **BallArena Test**.

Для промежуточного теста проверьте главное меню, выбор всех шести текущих героев, свободный бой, первый уровень и бой с 20 участниками. Обратите внимание на читаемость, удобство кнопок и плавность. Ранее владелец проверял APK на OnePlus Nord CE5 и сообщал о замедлении при массовом бое; после исправлений производительности нужен отдельный повторный замер на устройстве.

## Повторная сборка

В основной папке проекта запустите PowerShell-команду:

```powershell
.\tools\build_android.ps1
```

Готовый APK появится в `builds/android/BallArena-test.apk`, журналы импорта и экспорта — в `builds/android/import.log` и `builds/android/export.log`. Скрипт проверяет оба этапа отдельно и не принимает нулевой exit Godot за успех при ошибках в журнале. В редакторе Godot также можно открыть **Проект → Экспорт → Android Test → Экспорт проекта**, оставив включённой отладочную сборку. Если Godot находится в другом месте, передайте путь через `-GodotPath`.

- Android SDK: `C:/Users/STerrible/AppData/Local/Android/Sdk`; установлены command-line tools, platform-tools, Build-Tools 36.0.0 и платформа Android 36. Версии 34 и 35 сохранены.
- Godot Android-шаблоны debug/release 4.7.2: `C:/Users/STerrible/AppData/Roaming/Godot/export_templates/4.7.2.stable`.
- Пути SDK/Java сохранены в пользовательских настройках Godot, отладочный ключ используется штатный. Ключи не добавлены в репозиторий.
- В `project.godot` включён импорт ETC2/ASTC и указана небольшая SVG-иконка приложения. Параметры персонажей и физики не изменены.
- Загрузчик профилей использует ResourceLoader, чтобы обнаруживать героев и после преобразования ресурсов в экспортируемой игре.
- Документация и автоматические тесты исключены из APK; интернет-разрешение не запрашивается.

Проверки: чистый итоговый экспорт без ERROR, подпись APK v2/v3, ZIP-выравнивание с учётом страниц 16 КБ, ARM64/ARMv7, манифест Android. Точные ресурсы из APK проверены локальным движком: обнаружены пять героев, открываются меню, запускаются свободный бой и первый уровень. Это проверка ресурсов и логики на Windows, а не запуск Android-приложения на телефоне.

Официальная инструкция: [Android-экспорт Godot](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_android.html). У Godot 4.7.2 фактический target SDK — 36; использована соответствующая версия SDK.
